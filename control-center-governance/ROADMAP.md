# Roadmap

## المرحلة 1 — الأساس

- إنشاء هيكل المستودع وقوالب التوثيق.
- تعريف Gates من 0 إلى 8.
- إضافة مولّد Evidence محلي.
- إضافة GitHub Action للتحقق الأساسي.

## المرحلة 2 — Gate Engine

- تحويل شروط Gate إلى بيانات قابلة للقراءة آليًا.
- دعم انتقالات Gate المسموح بها.
- إصدار قرار موحد مع أسباب الحجب.

## المرحلة 3 — تكامل المشاريع

- ربط مستودعات المشاريع بسجل مركزي.
- حفظ baseline وdeployment URL وWorkflow Run.
- إضافة تقارير حالة دورية.

## المرحلة 4 — الحوكمة المتقدمة

- تفعيل Branch Protection وRequired Checks.
- إضافة قوالب Pull Request وIssue.
- إضافة AI Auditor بصلاحية قراءة فقط.

## معايير الانتقال

لا تبدأ مرحلة جديدة قبل أن يكون للمرحلة السابقة Evidence مرتبط بـSHA، وأن تكون جميع شروط Gate المعني في حالة `PASS` أو موثقة كاستثناء معتمد في `DECISIONS/`.
