# Project Registry

هذا السجل هو نقطة الدخول الموحدة لمتابعة المشاريع المرتبطة بمركز التحكم. كل مشروع يجب أن يملك ملفًا مستقلًا يحدد المستودع، الفرع المرجعي، Gate الحالي، الـbaseline، وأوامر التحقق المتاحة.

## دورة التسجيل

عند تسجيل مشروع جديد، أضف ملفًا إلى هذا المجلد اعتمادًا على `project-profile.template.md`. لا يُعتبر المشروع مجتازًا لأي Gate بمجرد تسجيله؛ يجب إنشاء Evidence مستقل مرتبط بآخر SHA والتحقق من أوامر المشروع الفعلية.
