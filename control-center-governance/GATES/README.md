# Gate Governance

كل ملف داخل هذا المجلد يمثل مرحلة قابلة للتحقق. يجب أن يجيب كل Gate عن أربعة أسئلة: ما الشروط؟ ما الدليل المطلوب؟ ما الـbaseline؟ وما الذي يمنع الانتقال؟

## الحالات المسموحة

| الحالة | المعنى |
|---|---|
| `TODO` | لم يبدأ التحقق |
| `IN_PROGRESS` | التحقق جارٍ |
| `PASS` | كل الشروط مستوفاة مع Evidence |
| `BLOCK` | يوجد شرط يمنع الانتقال |
| `WAIVED` | استثناء موثق في قرار تقني |

## قالب القرار

يجب أن يحتوي كل Gate على رقم الإصدار، الحالة الحالية، SHA المرجعي، شروط القبول، رابط Evidence، وملاحظات الاستثناءات إن وجدت. التعريف التنفيذي المقابل موجود في `gates.json`، ويُقيّمه `SCRIPTS/gate-engine.py`. لا تُستخدم الموافقة اليدوية وحدها كبديل عن Evidence التنفيذي.
